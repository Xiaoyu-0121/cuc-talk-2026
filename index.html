  • 它提出了 Transformer 这个结构
  • 今天的 ChatGPT、Claude，还有 Sora、Seedance 这类视频模型，地基都是它
  • 核心只有一个想法：注意力
  • “T” in GPT 就是 Transformer。
  • 为什么一篇论文这么重要：它让模型可以“同时看完一整段”，而不是一个字一个字地读；这让它能吃下互联网量级的数据，规模一上去，能力就涌现了。
  • 现在主流的图像 / 视频模型也大量采用 Transformer 结构（比如 DiT），所以说它是共同地基。
什么是“注意力”

每个词都回头看一眼其他所有词，
再决定自己是什么意思。

  • 第一句：“它”是谁？人一看就知道是相机，因为“没电”。模型的做法是让“它”回头给每个词打分，“相机”分最高——这就是注意力。
  • 翻一下（下一步）：只改了后半句，“他”就去看“摄影师”了。意思是靠上下文算出来的。
  • 类比：剪辑师看一个镜头，永远要结合前后镜头才知道它在片子里是什么意思。

一万道题
答案背不下，只能学会公式。
公式一旦会了，新题也会做。
它不是想理解。是为了把下一个词猜准，被迫去理解。
  • 这一页展开上一页那句“猜得足够好，就像在思考”。依据是知乎 bigpunch 的回答《为什么 LLM 仅预测下一词，就能涌现出高级能力》，赞同过万。屏幕上只留三个例子，下面这些口头讲。
  • 压缩：模型比整个互联网小得多。死记硬背背不下，想把下一个词猜准，就只能抓住生成这些文字的规律。像背圆周率，背几百位就到头；学会公式，才能一直往下算。
  • 第一个例子是物理和因果：钥匙、锁、“咔嚓”、门开。第二个是长程记忆加推理：不理解前文，最后一句一定猜错。
  • 第三个例子讲涌现：小模型靠统计共现，看到“人工”就接“智能”。大到某个点，光靠共现降不了错误率，它从“记答案”切到“学方法”。像烧水，99 度还是水，100 度变成气。数据太大背不下来，它被逼出通解。
  • 可以补一句：训练数据里的代码尤其硬，少一个括号就错。它为了猜对代码，学会跟踪状态和严格逻辑，这套能力会迁移到写作。
  • 收在屏幕最后一句。别展开流形、贝叶斯。文字是人类思维留下的痕迹，猜文字就是在学这些痕迹怎么接下去。
图像和视频模型在做什么
step 0 / 40示意动画

从噪点里显影

训练时：把一张好图一点点弄脏，直到变成雪花。

让模型学会反过来——每次只擦掉一点点脏。

生成时：从一片纯噪点开始，按你的描述，一步步“洗”出画面。

视频 = 再加上时间这一维。

  • 这叫扩散模型（Diffusion）。对学过摄影的人来说，很像暗房显影：相纸泡在显影液里，影像是慢慢浮出来的——先有大的明暗，再有细节。
  • 注意看动画：先出现的是大色块和构图，最后才是细节。真实模型也是这样，所以提示词里的构图、光线往往比细节描述更“决定命运”。
  • 视频难在哪：每一帧都要洗干净，而且帧和帧之间要连贯——人不能走着走着换了张脸，杯子不能穿过手。

Agent 智能体

你给它一个目标，它自己想、自己动手、自己看结果，不满意就再来一轮——直到做完。
Agent = 模型 + 工具 + 循环 + 上下文
  • 举例：让 Agent 做一条片子。它会先写脚本 → 调生图模型出分镜 → 自己看一眼，觉得角色不一致 → 重新生成 → 调视频模型 → 配音配乐 → 剪辑。中间每一步都是“想 → 做 → 看”。
  • 区别就像：聊天机器人是顾问，Agent 是能自己跑项目的执行制片。

Context 工程2025
这一刻，让它看什么

模型一次能看的东西有限，看得太多也会走神。

像副导演每天发的通告单：今天拍哪几场、几点到、带什么，而不是把整本剧本塞给每个人。

卡在哪每一步都做对还不够，几十步连起来，总有一步会翻车。
生成第 3 个镜头时，它眼前放着
✓品牌 brief（一页）
✓主角的参考图
✓前两个镜头的成片
✓第 3 个镜头的分镜描述
故意不放进来的：
✗前面 200 轮聊天记录
✗用不上的其他手册全文
✗被否掉的 3 版旧脚本
放多了：忘了主角长什么样。放少了：开始瞎猜。
  • Context 就是“模型在这一刻能看到的全部东西”。它像人的工作记忆，有上限，而且塞得越满越容易抓不住重点。
  • 很多 Agent 犯错，不是因为模型笨，而是因为它当时眼前的东西不对：要么关键信息被淹没了，要么根本没给它。
  • 所以工程师的活变成了：每一步开工前，精心挑选放到它面前的那几页。

Harness 工程2026
搭一个能把活干完的片场

Harness 原意是马具：模型是马，harness 是缰绳、车辕和整辆车。

Claude Code、Codex、VidMuse，本质上都是 harness。同一个模型，换一套 harness，判若两人。

现在大家在卷的，主要就是这一层。
一套 HARNESS 替你跑的流程
01
拆任务脚本 → 7 个镜头，每个镜头一张任务卡
02
并行生成7 个镜头同时开工
03
自动质检不合格 → 打回重做主角是同一个人吗？时长对吗？店名写错了吗？
04
存档做到一半断了，也能接着做
05
交给你确认你说“第 4 个镜头太暗”，只重做这一个
  • 前四步解决的都是“某一步怎么做对”，Harness 解决的是“整件事怎么稳定地做完”：拆任务、并行、检查、重试、存档、和人确认。
  • 类比剧组：演员再好，也需要统筹排期、场记记录、监视器回看、导演喊“再来一条”。Harness 就是这一整套片场机制。
  • 行业里的共识是：同一个模型，放进不同的 harness，效果可以差很多。所以现在很多团队的核心竞争力不在模型，而在 harness。

04
注意力不会变多
片子可以无限做出来。每个人一天还是二十四小时。
红果的总使用时长，已经排到全国第四。
  • 01：就像录音普及以后，现场演出反而更值钱。电影院卖的会越来越是“和一群人一起在黑暗里看”的体验。
  • 02：广告可以为每个用户生成一版；生日视频、家庭纪录片、给一个人写的歌，会变得很普通。
  • 03：我们上学那会儿（2014—2015），手机 + 4G + B站 / 公众号，一批有想法的人不靠电视台也能被看见。这一次门槛更低，而且天生全球化。
  • 04：和 03 分开。03 讲谁来做，04 讲时间给谁。供给可以趋近无穷，注意力是固定的，多出来的内容在抢同一块屏幕时间。
  • 口径别说满：2026 年 10 月，抖音副总裁李亮说，按用户总使用时长，红果排中国移动互联网第四，仅次于抖音、微信、抖音极速版。不是“用户数第四”。QuestMobile：7 月日活 1.68 亿，超过爱优腾芒日活之和；8 月人均大约 151 分钟。
  • 消费上的变化：被吃掉的是碎片时间，短、密、上头。长视频和院线变成低频——这和 01“电影变成演唱会”是同一件事的两面。
  • 可以问一句：你们自己的屏幕时间里，抖音、红果、B 站各占多少？

审美 · 判断什么是好的

连最前沿的模型公司，
都很难把它量化。

难点一

审美长在语境里

一个西方收藏家买下一件非洲部落的手工艺品——他看到的美，和做它、用它的人看到的，不是同一种美。

要描述你所说的“有教养的趣味”，你就必须描述一种文化。—— 维特根斯坦《美学讲演》
难点二

审美是极高倍率的压缩

你看到的形式，是背后大量思考压缩后的结果。好作品的形式和主题是一体的。

只模仿表面，就像拿到一个压缩包，却没有解压的钥匙：学会小津的低机位，不等于学会他看家庭的方式。

  • 接回前面那句“最难的是把什么是好写清楚”。做模型数据和评测时最深的体会：两个专业的人给同一条视频打分，可能差很远；你很难写出一条规则让机器“学会好看”。（可以讲一个自己做标注 / 评测时的真实例子。）
  • 难点一：审美不是一个普适的分数，它离不开那个人、那个地方、那套生活。
  • 难点二：小津的低机位，常被解释为跪坐在榻榻米上的视线——形式就是他看待家庭的方式本身。只学形式，学不到那个“为什么”。
审美 · 我没办法教大家什么是好的
“学摄影，归根到底
是要去洗眼睛。”
—— 孙振虎老师，《摄影流派与发展史》课上
多去看，多去想：好的画、好的展览、好的建筑、好的电影。
  • 先说清楚：我没办法以老师的身份讲什么是好审美，在座可能有人审美比我好得多。
  • 讲到这里，总会想起已故的孙振虎老师。他在课上说的这句话，我到现在还觉得是最准确的。
  • 在 AI 时代，这句话反而更重要了：做东西变便宜了，看东西的眼睛变贵了。
落到明天能做的事

几个具体的小建议

  • 建一个自己的“好东西库”
    存下打动你的东西，写一句为什么。这就是你的评测集。
  • 每天做完一个小东西
    试错成本已经低到可以“日更”。做完，比做好重要。
  • 然后，把它发出去
    Attention is all you need，对每个人也一样。好工作可能更难找，但做个人 IP、做一人公司（OPC）的机会会更多。
  • 练习提问
    高质量的提问，比解决问题重要得多。把问题问好的过程，就是把一件事想深的过程。
  • 去上游实习一次
    品牌方、营销、投放。看一条内容是怎么被决定要做的。
  • 保持手感
    每个月，把每个模态的第一名亲手试一遍。
  • 每条点一下就行，不用展开，重点讲“发出去”和“提问”。
  • “好东西库”和我工作里做评测是一回事：你攒的不是图片，是你自己的判断标准。
  • 发出去：呼应开头那篇论文的标题。未来内容极度过剩，稀缺的是注意力，对个人也一样。找到一份好工作可能会更难，但打造个人 IP、做一人公司（OPC, One Person Company）的机会会更多。做了不发，等于没做。
  • 练习提问：AI 让“解决问题”变得便宜，“提出好问题”变得值钱。把一个问题问清楚、问准，本身就是对这件事思考不断深入的过程。
